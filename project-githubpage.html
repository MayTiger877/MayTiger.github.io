Personal Portfolio Website

( where you are right now! )

Started as a way to present my work professionally, this project became a practical exercise in frontend development, UI design, deployment, and media integration. It gave me experience outside of my usual systems and software engineering work while reinforcing the value of building complete products from idea to deployment.

The website was designed around a "PS2 game menu" inspired aesthetic, combining retro UI influences with modern responsive web development practices. The result is a lightweight static website hosted through GitHub Pages.

Features

🌐

Multi-page Architecture

Separated content into dedicated pages for experience, projects, plugins, music, and personal information while maintaining a consistent UI.

🎧

Audio Integration

Implemented startup sounds, background ambience, embedded music playback, and media handling directly within the browser.

📱

Responsive Design

Converted layouts from fixed pixel dimensions into scalable responsive units to improve usability across different screen sizes.

What I Learned

Frontend Fundamentals
Gained hands-on experience building a complete website using vanilla HTML, CSS, and JavaScript without relying on frameworks.
UI / UX Design
Learned how visual hierarchy, spacing, navigation, and feedback influence the overall user experience.
Work with AI
Used AI tools to assist with design, content generation, and coding tasks, improving how to effectively leverage these tools while maintaining creative control.
